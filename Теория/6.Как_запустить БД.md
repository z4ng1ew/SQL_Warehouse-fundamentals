Давай по шагам. Тебе нужно применить SQL-скрипт к PostgreSQL через PowerShell.

## Предварительно

Убедись, что PostgreSQL установлен и `psql` доступен. Проверь в PowerShell:

```powershell
psql --version
```

Если команда не найдена, значит путь к psql не добавлен в переменную окружения PATH (системная переменная, указывающая ОС, где искать исполняемые файлы). Обычно psql лежит в чём-то вроде:

```
C:\Program Files\PostgreSQL\16\bin\
```

В таком случае либо добавь этот путь в PATH, либо используй полный путь к psql в командах ниже.

## Шаг 1 — Подключись к PostgreSQL и создай базу данных

```powershell
psql -U postgres
```

`-U postgres` — подключение под пользователем postgres (суперпользователь PostgreSQL, создаётся при установке). Тебя попросят ввести пароль — тот, что ты задавал при установке PostgreSQL.

После подключения создай базу данных для задания:

```sql
CREATE DATABASE rush01;
\q
```

`\q` — команда выхода из psql.

## Шаг 2 — Примени скрипт

Предположим, файл `rush01_model.sql` лежит, например, в `C:\Users\ТвоёИмя\Downloads\`. Тогда:

```powershell
psql -U postgres -d rush01 -f "C:\Users\ТвоёИмя\Downloads\rush01_model.sql"
```

Разбор флагов:
- `-U postgres` — имя пользователя
- `-d rush01` — имя базы данных, к которой подключаемся
- `-f "путь\к\файлу.sql"` — выполнить SQL-скрипт из файла

## Шаг 3 — Проверь, что всё загрузилось

```powershell
psql -U postgres -d rush01
```

И внутри psql:

```sql
-- посмотри список таблиц
\dt

-- проверь данные
SELECT * FROM "user";
SELECT * FROM currency;
SELECT * FROM balance;
```

Ты должен увидеть три таблицы и данные в них: 3 пользователя, 8 записей валют, 10 записей балансов.

## Если что-то пошло не так

**«Ошибка аутентификации»** — неправильный пароль. Если забыл, можно сбросить через файл `pg_hba.conf` (PostgreSQL Host-Based Authentication — файл настроек аутентификации), но это отдельная тема.

**«Отношение уже существует»** — значит скрипт уже применялся. Сначала удали старые таблицы:

```sql
DROP TABLE IF EXISTS balance;
DROP TABLE IF EXISTS currency;
DROP TABLE IF EXISTS "user";
```

И примени скрипт заново.

**«psql не найден»** — используй полный путь:

```powershell
& "C:\Program Files\PostgreSQL\16\bin\psql.exe" -U postgres -d rush01 -f "путь\к\rush01_model.sql"
```

Символ `&` в PowerShell — это call operator (оператор вызова), нужен когда путь к программе содержит пробелы и берётся в кавычки.
