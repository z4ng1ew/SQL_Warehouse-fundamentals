## Алгоритм настройки базы данных для задания (Windows + PowerShell + PostgreSQL)

### Шаг 1 — Создание базы данных

В PowerShell (не внутри psql):

```powershell
psql -U postgres -c "CREATE DATABASE rush01 ENCODING 'UTF8';"
```

Вводишь пароль от пользователя postgres.

### Шаг 2 — Подключение с правильной кодировкой

```powershell
chcp 65001
psql -U postgres -d rush01
```

`chcp 65001` — переключает консоль на UTF-8. Без этого кириллица не отобразится вообще (хотя у нас и с этим отображение не идеальное, но данные хранятся корректно).

### Шаг 3 — Установка кодировки клиента внутри psql

```sql
SET client_encoding TO 'UTF8';
```

### Шаг 4 — Создание таблиц и вставка данных

**Таблицы без кириллицы** (currency, balance) — вставляешь обычным SQL, копируя из файла задания. Проблем не будет.

**Таблицы с кириллицей** (user) — стандартный PowerShell **не умеет** передавать кириллицу в psql. Поэтому используешь **Unicode-escape синтаксис** PostgreSQL — `U&'\0418\0432\0430\043D'` вместо `'Иван'`:

```sql
insert into "user" values (1, U&'\0418\0432\0430\043D', U&'\0418\0432\0430\043D\043E\0432');
insert into "user" values (2, U&'\041F\0435\0442\0440', null);
insert into "user" values (3, null, U&'\0421\0438\0434\043E\0440\043E\0432');
```

Таблица соответствий для этих данных:

| Буква | Код |
|-------|-----|
| И | `\0418` |
| в | `\0432` |
| а | `\0430` |
| н | `\043D` |
| о | `\043E` |
| П | `\041F` |
| е | `\0435` |
| т | `\0442` |
| р | `\0440` |
| С | `\0421` |
| и | `\0438` |
| д | `\0434` |

### Шаг 5 — Проверка

```sql
\dt                          -- должно быть 3 таблицы
SELECT count(*) FROM "user";     -- 3 строки
SELECT count(*) FROM currency;   -- 8 строк
SELECT count(*) FROM balance;    -- 10 строк
```

Кириллицу проверяешь через длину, а не визуально:

```sql
SELECT id, length(name), length(lastname) FROM "user";
-- id=1: length 4 (Иван), length 6 (Иванов)
-- id=2: length 4 (Петр), lastname NULL
-- id=3: name NULL, length 7 (Сидоров)
```

### Если нужно удалить всё и начать заново

Выйди из psql (`\q`), потом в PowerShell:

```powershell
psql -U postgres -c "DROP DATABASE IF EXISTS rush01;"
psql -U postgres -c "CREATE DATABASE rush01 ENCODING 'UTF8';"
```

И повтори с Шага 2.

### Важные грабли, которые мы прошли

- **Не вводи команды PowerShell внутри psql** — `psql -U postgres` это команда для PowerShell, а не SQL
- **Не вставляй весь скрипт разом** — если одна строка сломается (кириллица), psql «зависнет» в незакрытой кавычке, и всё остальное тоже пропадёт. Вводи по одной команде
- **`Ctrl+C`** — если psql застрял (промпт показывает `'#` или `(#` вместо `=#`), нажми Ctrl+C для отмены
- **Файлы .sql в Windows-1251** не работают напрямую с UTF-8 базой. `Set-Content -Encoding UTF8` в PowerShell добавляет BOM (невидимые байты в начале файла), что тоже ломает SQL
