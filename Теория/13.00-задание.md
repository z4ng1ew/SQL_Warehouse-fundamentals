## Задание 00 простым языком

Представь, что ты работаешь в банке. У тебя есть три таблицы:

- **User** — список клиентов (Иван, Петр, Сидоров)
- **Balance** — все операции с деньгами (кто, сколько, в какой валюте)
- **Currency** — курсы валют (EUR, USD, JPY) с историей изменений

Руководство банка спрашивает: **«Сколько денег в долларах у каждого клиента по каждому типу операций?»**

## Разбор на конкретном примере

Возьмём Ивана (id=1). В таблице balance у него три записи:

```
user_id=1, money=20,  type=1, currency_id=100 (EUR)
user_id=1, money=200, type=1, currency_id=100 (EUR)
user_id=1, money=190, type=1, currency_id=100 (EUR)
```

Все три — тип 1, валюта EUR. Задание говорит: **просуммируй** все money по группе (пользователь + тип + валюта):

```
volume = 20 + 200 + 190 = 410 EUR
```

Но 410 EUR — это **сколько в долларах**? Для этого нужен курс.

## Зачем `last_rate_to_usd`

В таблице currency для EUR (id=100) есть **несколько** курсов (потому что курс менялся):

```
EUR  0.9   — 03.03.2022 13:31  ← самый свежий!
EUR  0.89  — 02.03.2022 12:31
EUR  0.87  — 02.03.2022 08:00
EUR  0.9   — 01.03.2022 15:36
```

Какой брать? Задание говорит: **последний** (самый свежий по дате). Это `0.9` от 03.03.2022. Вот это и есть `last_rate_to_usd` — **последний актуальный курс** валюты к доллару.

## Зачем `total_volume_in_usd`

Это финальный ответ для руководства: **сколько это в долларах**.

```
total_volume_in_usd = volume * last_rate_to_usd
                    = 410   * 0.9
                    = 369 USD
```

То есть 410 евро по курсу 0.9 = **369 долларов**.

## Зачем «аномалии»

Не все данные идеальны:

**User_id=4** есть в balance, но **нет** в таблице user. Кто это? Неизвестно. Но задание говорит: обработай его тоже, имя и фамилия будут `'not defined'`.

**User_id=2 (Петр)** имеет currency_id=210, но такой валюты **нет** в таблице currency. Название валюты будет `'not defined'`, курс — `1` (по умолчанию).

**User_id=3** — имя NULL. Тоже ставим `'not defined'`.

## Итого — что показывает каждая колонка

| Колонка | Что это простым языком |
|---------|----------------------|
| name | Имя клиента (или 'not defined' если неизвестен) |
| lastname | Фамилия клиента |
| type | Тип операции (0, 1, 2...) |
| volume | Сумма всех денег по этой группе |
| currency_name | В какой валюте эти деньги |
| last_rate_to_usd | Последний курс этой валюты к доллару |
| total_volume_in_usd | Сколько это в долларах (volume × курс) |

Руководство банка получает таблицу и видит: «У Ивана по операциям типа 1 лежит 410 евро, что равно 369 долларам по последнему курсу».
