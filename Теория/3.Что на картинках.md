## Что на картинках

**Schema (Image 1)** — структура таблиц в DWH. Обрати внимание: между таблицами **нет линий связи** (нет FK — foreign key, внешних ключей). Это и есть те самые "Virtual Foreign Keys" — связь подразумевается логически (`balance.user_id` → `user.id`, `balance.currency_id` → `currency.id`), но база её не проверяет.

**T01_01 (Image 2)** — концепция **Single Version of Truth** (единая версия правды) по Инмону. Из центрального нормализованного хранилища данные раздаются в **Data Mart Layer** (витрины данных — небольшие тематические хранилища для конкретных отделов/задач). **SCV** здесь — скорее всего **Single Customer View** (единое представление клиента).

**T01_02 и T01_03 (Image 3, 4)** — фотографии двух "отцов" DWH: Bill Inmon (подход "сверху вниз" — сначала строим единое нормализованное хранилище) и Ralph Kimball (подход "снизу вверх" — строим отдельные звёздные схемы / витрины).

**T01_04 (Image 5)** — слои классического DWH: **RAW** (сырые данные) → **ODS** (Operational Data Store — оперативное хранилище, копия "как есть") → **DDS** (Dimensional Data Store — измерительное/аналитическое хранилище) → **Mart Store** (витрины/отчёты). Сбоку — **MDM** (Master Data Management — управление мастер-данными, то есть единый справочник сущностей).

**T01_05 (Image 6)** — самая важная для задания схема. Показывает **CDC** (Change Data Capture — захват изменений данных) — процесс переноса данных из источников в DWH. Видно, что в DWH к таблицам `Balance` и `Currency` добавляется столбец `updated` (выделен красным) — это превращает обычную реляционную модель в **темпоральную** (хранящую историю изменений).

**T01_06 (Image 7)** — ключевая схема для **Exercise 01**. На временной оси:
- Зелёная точка наверху — момент транзакции (`balance.updated`)
- Красная точка слева — курс валюты **до** транзакции (t1 — расстояние до ближайшего прошлого курса)
- Оранжевая точка справа — курс валюты **после** транзакции (t2 — расстояние до ближайшего будущего курса)
- Логика: сначала берём t1 (прошлое), если прошлого нет — берём t2 (будущее)
