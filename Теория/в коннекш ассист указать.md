Это SQLTools в VS Code. Заполни так:

| Поле | Значение |
|------|----------|
| **Connection name** | `rush01` (любое имя, просто для отображения) |
| **Connection group** | оставь пустым |
| **Connect using** | `Server and Port` (уже выбрано) |
| **Server Address** | `localhost` (уже указано) |
| **Port** | `5432` (уже указано) |
| **Database** | `rush01` |
| **Username** | `postgres` |
| **Use password** | выбери **SQLTools Driver Credentials** (уже выбрано), потом введи свой пароль от postgres |

Нажми **Connect** (или **Save Connection** / **Test Connection**). После подключения выполни запрос:

```sql
SELECT * FROM "user";
```

В VS Code кириллица **Иван**, **Петр**, **Сидоров** должна отображаться корректно, потому что VS Code работает в UTF-8 по умолчанию.
