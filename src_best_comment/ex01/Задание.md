## Задание 01 простым языком

В задании 00 мы брали **последний** курс валюты для всех транзакций. Тут сложнее — нужно для **каждой транзакции** найти **свой** курс, ближайший по времени.

## Аналогия из жизни

Представь, ты менял деньги в обменнике несколько раз в разные дни. И хочешь узнать: «По какому курсу **реально** можно было обменять в тот день?»

Ты не берёшь сегодняшний курс — ты ищешь курс, который **действовал** в момент операции.

## Конкретный пример

Иван (id=1) совершил транзакцию:

```
money=200, currency_id=100 (EUR), updated=2022-01-09 13:31
```

Вопрос: **какой курс EUR использовать?**

Смотрим все курсы EUR в таблице currency:

```
EUR  0.85  — 2022-01-01 13:29   ← в прошлом (до 2022-01-09)
EUR  0.79  — 2022-01-08 13:29   ← в прошлом (до 2022-01-09) ← БЛИЖАЙШИЙ!
EUR  0.9   — 2022-03-01 15:36   ← в будущем
EUR  0.87  — 2022-03-02 08:00   ← в будущем
EUR  0.89  — 2022-03-02 12:31   ← в будущем
EUR  0.9   — 2022-03-03 13:31   ← в будущем
```

**Шаг 1** — ищем ближайший курс **в прошлом** (updated < 2022-01-09 13:31). Нашли два: 0.85 (1 января) и 0.79 (8 января). Ближайший к 9 января — **0.79** от 8 января.

**Шаг 2** — курс в прошлом нашёлся, значит будущее **не смотрим**.

**Результат:** `200 * 0.79 = 158`

## Когда используется курс из будущего

Пользователь id=4, транзакция:

```
money=120, currency_id=200 (USD), updated=2022-01-01 01:31
```

Курсы USD:

```
USD  1  — 2022-03-02 12:31   ← в будущем
USD  1  — 2022-03-03 13:31   ← в будущем
```

В прошлом (до 2022-01-01 01:31) курсов USD **нет вообще**. Тогда берём ближайший **из будущего** — `1` от 2022-03-02.

**Результат:** `120 * 1 = 120`

## Чем отличается от задания 00

| | Задание 00 | Задание 01 |
|---|-----------|-----------|
| Курс | Один **последний** для каждой валюты | **Свой** для каждой транзакции (ближайший по времени) |
| Группировка | SUM(money) — суммируем транзакции | Без группировки — **каждая** транзакция отдельно |
| Валюты без ключа | Показываем как 'not defined' | **Игнорируем** (INNER JOIN вместо FULL JOIN) |
| Вывод | 7 столбцов | 4 столбца |

## Что значит «игнорируйте валюты, отсутствующие в Currency»

У Петра (id=2) currency_id=210. Такой валюты **нет** в таблице currency. В задании 00 мы его показывали с `'not defined'`. В задании 01 — просто **выкидываем**. Поэтому Петра не будет в результате вообще.
