Мы выбираем 4 столбца из таблицы balance:

```sql
SELECT user_id, type, currency_id, SUM(money) AS volume
--     ^^^^^^   ^^^^  ^^^^^^^^^^^  ^^^^^^^^^^^^^^^^^^^^
--       1       2        3                4
```

Первые три — обычные столбцы, берутся как есть из таблицы balance.

Четвёртый — **вычисляемый**: `SUM(money)` складывает все значения `money` внутри группы, а `AS volume` даёт результату имя `volume`.

Работает вместе с `GROUP BY`:

```sql
SELECT user_id, type, currency_id, SUM(money) AS volume
FROM balance
GROUP BY user_id, type, currency_id
```

Пример. В balance три строки Ивана:

```
user_id=1, type=1, currency_id=100, money=20
user_id=1, type=1, currency_id=100, money=200
user_id=1, type=1, currency_id=100, money=190
```

У всех трёх одинаковые `user_id`, `type`, `currency_id` — значит это **одна группа**. `SUM(money)` считает: 20 + 200 + 190 = 410. Результат:

```
user_id=1, type=1, currency_id=100, volume=410
```

Три строки **схлопнулись** в одну с итоговой суммой.
