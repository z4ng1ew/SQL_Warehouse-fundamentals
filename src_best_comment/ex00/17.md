```sql
  COALESCE(lr.rate_to_usd, 1)                        AS last_rate_to_usd, - а почему если  валюта не найдена — подставляем 1 - это в задании указанно ?
```


Да, это прямо указано в задании. Вот цитата из таблицы формул:

> **last_rate_to_usd** — источник: currency.rate_to_usd; взять последний rate_to_usd для соответствующей валюты; **если currency.rate_to_usd IS NULL, то вернуть 1**

## Почему именно 1

Это имеет логический смысл. Курс валюты к доллару = 1 означает «один к одному». То есть если мы **не знаем** курс, предполагаем, что 1 единица этой валюты = 1 доллар.

Посмотри на примере Петра (id=2). У него `currency_id=210`, а такой валюты **нет** в таблице currency. LEFT JOIN вернёт NULL для `rate_to_usd`. Что делать?

```sql
COALESCE(NULL, 1)  →  1
```

Тогда:

```
total_volume_in_usd = volume * 1 = volume
-- то есть 203 * 1 = 203
```

Если бы подставили 0 — все деньги «обнулились» бы: `203 * 0 = 0`. Это было бы неправильно — деньги-то есть, просто курс неизвестен.

Если бы подставили NULL — результат умножения тоже стал бы NULL: `203 * NULL = NULL`. Строка пропала бы из отчёта.

Единица — самый **безопасный** вариант по умолчанию: деньги сохраняются «как есть», без конвертации.
