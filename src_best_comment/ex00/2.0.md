## Разбор `SELECT DISTINCT ON (id) id, name, rate_to_usd`

### Обычный DISTINCT (без ON)

Ты наверняка знаешь обычный `DISTINCT` — он убирает **полностью одинаковые строки**:

```sql
SELECT DISTINCT name FROM currency;
-- EUR, USD, JPY — убрал дубликаты по name
```

### DISTINCT ON (столбец) — PostgreSQL-фишка

`DISTINCT ON (id)` говорит: «Из всех строк с **одинаковым id** оставь только **одну**». Какую именно — определяет `ORDER BY`.

Полная конструкция из нашего запроса:

```sql
SELECT DISTINCT ON (id) id, name, rate_to_usd
FROM currency
ORDER BY id, updated DESC
```

Что происходит пошагово:

**Шаг 1** — PostgreSQL берёт все строки currency и сортирует по `id, updated DESC`:

```
id=100, EUR, 0.9,    2022-03-03 13:31  ← первая для id=100
id=100, EUR, 0.89,   2022-03-02 12:31
id=100, EUR, 0.87,   2022-03-02 08:00
id=100, EUR, 0.9,    2022-03-01 15:36
id=200, USD, 1,      2022-03-03 13:31  ← первая для id=200
id=200, USD, 1,      2022-03-02 12:31
id=300, JPY, 0.0087, 2022-03-03 13:31  ← первая для id=300
id=300, JPY, 0.0079, 2022-03-01 13:31
```

**Шаг 2** — `DISTINCT ON (id)` берёт **первую строку** из каждой группы с одинаковым id:

```
id=100, EUR, 0.9     ← самый свежий курс EUR
id=200, USD, 1       ← самый свежий курс USD
id=300, JPY, 0.0087  ← самый свежий курс JPY
```

### Альтернатива без DISTINCT ON

То же самое можно написать через `ROW_NUMBER()`, но длиннее:

```sql
SELECT id, name, rate_to_usd
FROM (
    SELECT id, name, rate_to_usd,
           ROW_NUMBER() OVER (PARTITION BY id ORDER BY updated DESC) AS rn
    FROM currency
) sub
WHERE rn = 1
```

`DISTINCT ON` делает то же самое в одну строку. Но это **только PostgreSQL** — в MySQL, Oracle, MS SQL такой конструкции нет.
