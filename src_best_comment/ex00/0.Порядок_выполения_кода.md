## Порядок выполнения запроса

SQL выполняется **не сверху вниз**, а в определённом порядке. Вот как PostgreSQL обрабатывает этот запрос:

### Шаг 1 — CTE `last_rates`

```sql
WITH last_rates AS (
    SELECT DISTINCT ON (id) id, name, rate_to_usd
    FROM currency
    ORDER BY id, updated DESC
)
```

PostgreSQL первым делом выполняет WITH-блоки. Берёт таблицу currency (10 строк), сортирует по `id, updated DESC`, и `DISTINCT ON (id)` оставляет по одной строке на валюту. Результат — **временная таблица** в памяти:

```
id=100, EUR, 0.9
id=200, USD, 1
id=300, JPY, 0.0087
```

### Шаг 2 — CTE `volumes`

```sql
volumes AS (
    SELECT user_id, type, currency_id, SUM(money) AS volume
    FROM balance
    GROUP BY user_id, type, currency_id
)
```

Берёт таблицу balance (10 строк), группирует по `user_id, type, currency_id`, считает SUM. Результат — ещё одна **временная таблица**:

```
user_id=1, type=1, currency_id=100, volume=410
user_id=2, type=2, currency_id=210, volume=203
user_id=3, type=0, currency_id=100, volume=50
user_id=3, type=1, currency_id=200, volume=500
user_id=3, type=2, currency_id=300, volume=500
user_id=4, type=0, currency_id=300, volume=120
user_id=4, type=1, currency_id=200, volume=120
```

### Шаг 3 — FROM + FULL JOIN + LEFT JOIN

```sql
FROM volumes AS v
FULL JOIN "user"     AS u  ON v.user_id = u.id
LEFT JOIN last_rates AS lr ON v.currency_id = lr.id
```

Сначала `FULL JOIN` — соединяет volumes с user. Каждая строка volumes получает имя и фамилию пользователя. Строки без пары **сохраняются** с обеих сторон (user_id=4 без пользователя, и пользователи без баланса если бы были).

Потом `LEFT JOIN` — к результату подтягивает last_rates. Каждая строка получает название валюты и курс. Если currency_id не найден (210) — lr.name и lr.rate_to_usd будут NULL.

### Шаг 4 — SELECT (вычисление столбцов)

```sql
SELECT
    COALESCE(u.name, 'not defined')                    AS name,
    COALESCE(u.lastname, 'not defined')                AS lastname,
    v.type,
    v.volume,
    COALESCE(lr.name, 'not defined')                   AS currency_name,
    COALESCE(lr.rate_to_usd, 1)                        AS last_rate_to_usd,
    trim_scale(v.volume * COALESCE(lr.rate_to_usd, 1)) AS total_volume_in_usd
```

Для каждой строки из шага 3 вычисляются 7 столбцов. COALESCE заменяет NULL на значения по умолчанию. `trim_scale` убирает лишние нули.

### Шаг 5 — ORDER BY (сортировка)

```sql
ORDER BY 1 DESC, 2, 3
```

Выполняется **последним**. Сортирует готовые строки: по первому столбцу (name) по убыванию, потом по второму (lastname) и третьему (type) по возрастанию.
