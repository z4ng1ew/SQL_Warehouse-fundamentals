Тут три элемента:

```sql
COALESCE(u.name, 'not defined')  AS name
^^^^^^^^ ^^^^^^  ^^^^^^^^^^^^^   ^^^^^^^
функция  1-й     2-й аргумент   алиас
         аргумент
```

**`COALESCE`** — функция, которая берёт первое **не-NULL** значение из списка аргументов.

**`u.name`** — первый аргумент. Столбец `name` из таблицы `"user"` (алиас `u`). Точка — обращение к столбцу конкретной таблицы.

**`'not defined'`** — второй аргумент. Строка-замена на случай, если `u.name` равно NULL.

**`AS name`** — алиас для результата. В выводе столбец будет называться `name`.

## Логика работы

```
Если u.name = 'Иван'  → COALESCE('Иван', 'not defined')  → 'Иван'
Если u.name = 'Петр'  → COALESCE('Петр', 'not defined')  → 'Петр'
Если u.name = NULL     → COALESCE(NULL, 'not defined')    → 'not defined'
```

Первый аргумент не NULL — вернул его. Первый аргумент NULL — перешёл ко второму.

## Зачем это нужно

В задании сказано: «если user.name равно NULL, то вернуть значение `not defined`». У пользователя id=3 имя — NULL (Сидоров без имени). Без COALESCE в результате было бы пустое поле, а задание требует текст `'not defined'`.

















COALESCE - что делает ?





**COALESCE** (читается «коалэс», от англ. «объединять, сливать воедино») — функция, которая перебирает аргументы **слева направо** и возвращает **первый не-NULL**.

```sql
COALESCE(a, b, c, d)
```

Логика: если `a` не NULL → вернёт `a`. Если `a` = NULL, проверит `b`. Если `b` не NULL → вернёт `b`. И так далее. Если **все** NULL → вернёт NULL.

## Примеры

```sql
COALESCE('Иван', 'not defined')    → 'Иван'       -- первый не NULL
COALESCE(NULL, 'not defined')      → 'not defined' -- первый NULL, берём второй
COALESCE(NULL, NULL, 'запасной')   → 'запасной'    -- первые два NULL, берём третий
COALESCE(NULL, NULL, NULL)         → NULL           -- все NULL
```

## Аналогия из жизни

Ты звонишь другу. Не отвечает → звонишь второму. Не отвечает → звонишь третьему. Кто первый ответил — с тем и говоришь.

```sql
COALESCE(друг_1, друг_2, друг_3)
```

## Аналогия на Си

```c
// Примерно то же самое на Си
char* result = (a != NULL) ? a : 
               (b != NULL) ? b : 
               (c != NULL) ? c : NULL;
```
